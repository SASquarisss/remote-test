你是一个专业的法律文本解析工具。请从以下案件文本中提取结构化信息。

## 提取规则
1. 当事人角色必须准确（严格按以下编码）：
   - 行政案件："plaintiff"（原告）、"defendant"（被告）
   - 刑事案件："defendant"（被告人）、"witness"（被害人）、"prosecutor"（公诉人）
   - 民事案件：根据上下文判断（如"诉称"方为"plaintiff"，"辩称"方为"defendant"）
   - 执行案件："applicant"（申请执行人）、"respondent"（被执行人）
   - 再审案件："retrial_applicant"（再审申请人）、"retrial_respondent"（再审被申请人）
   - 二审案件："appellant"（上诉人）、"appellee"（被上诉人）
   - 仲裁案件："applicant"（申请人）、"respondent"（被申请人）
   - 其他："third_party"（第三人）、"agent"（代理人）、"expert_witness"（鉴定人）、"interpreter"（翻译）
   - 无明确标签时标注"relator"（其他关联人）

2. 当事人类型：企业（含公司/集团/律所）、机关（含局/院/委员会）、自然人（2-4字姓名）、个体工商户、其他

3. 案号格式：(YYYY)地区法院简称+案由+第N号

4. 法条引用（重要）：仔细查找basic_facts、judgment_reason、judgment_essence、related_info中的法条，格式为《法典名》第X条第X款

5. 法院名称：完整名称

6. 错误容错规则：
   - 如果某个字段无法确定，请输空字符串""或空列表[]，不要整体报错
   - 如果JSON格式被截断，请确保已输出的部分是有效的JSON

## 输出格式
{
  "parties": [
    {"name": "名称", "role": "角色编码", "type": "自然人|企业|机关|个体工商户|其他"}
  ],

  "courts": ["法院1"],
  "law_refs": [
    {"statute": "法典名", "article": "条", "paragraph": "款"}
  ],
  "case_summary": "50字以内案件要点"
}
