# 原始数据目录

此目录存放未经处理的原始数据文件。

## 文件格式要求

| 项目 | 建议值 | 说明 |
|---|---|---|
| 格式 | CSV / TSV | 长文本字段建议用 TSV 避免逗号冲突 |
| 编码 | UTF-8 | 含 BOM 无均可 |
| 分隔符 | `\t` 或 `,` | TSV 为首选 |
| 引号 | `“`”` | 长文本字段必须用双引号包裹 |
| 换行符 | `\n` | 长文本内部不要有换行 |
| NULL 表示 | `\N` | 统一用 `\N` 代表空值 |
