# 深度思考图谱展示与交互优化设计方案 (v2 修正版)

针对你提出的三个犀利问题，我对前一版的交互方案进行了反思与重构。你的视角非常敏锐，特别是关于“链式思考结果累积”以及“图谱视图隔离”的需求，这直接触及了复杂知识图谱产品设计的核心痛点。

以下是针对你的疑问的详细答复及优化后的设计方案：

## 疑问解答与方案修正

### 疑问 1：链式思考中的五步结果，如何渲染在同一个浮窗中？如何区分？

**原方案痛点**：如果 5 个步骤的结果都在一个浮窗里互相覆盖，或者一股脑全部堆进去，会导致视觉混乱，失去“链式/步骤”的意义。

**优化方案：【增量累积 + 步骤高亮过滤】**
在浮窗（或专用的深度思考图谱视图）中，采用**“时间轴图层 (Timeline Layers)”**的渲染机制：
1. **累积渲染**：随着大模型从步骤 1 到步骤 5 的推演，浮窗里的图谱会**逐渐生长**。例如，第一步长出证据连线，第二步在证据基础上长出争议焦点。
2. **状态联动与区分**：
   - 当你在中间面板点击历史 Tab（如 `2. 诉求抗辩分析`）时，浮窗会自动响应。
   - **视觉区分策略**：此时，只有前两步生成的节点和边保持**全彩高亮**，而第 3、4、5 步生成的节点会被打上蒙版（如降低透明度 `opacity: 0.2` 或变成灰色虚线）。
   - 这样既能看清单步的产出，又能看到它在整条推演链中的相对位置。

---

### 疑问 2：既想看整合后的完整图谱，又想单独看深度思考的图谱，如何在页面上展示？

**原方案痛点**：“飞入主图谱”确实解决了融合问题，但大案件的主图谱动辄上百个节点，一旦融合，深度思考产生的那几个核心逻辑节点就会被淹没在事实和人员的汪洋大海中。

**优化方案：【主画布的“视界切换 (View Mode)”机制】**
我们不应该用两个物理容器（两个 Canvas）来分别装载它们，因为它们底层共享的是同一套数据。正确的做法是**在右侧的主舞台 (`ParseGraph`) 上增加一个“视界切换”开关**。

在右侧控制栏上方新增三个模式切换按钮：
1. **🌐 案件全貌视界 (Global View)**：
   - 行为：展示原始事实提取 + 深度思考所有的推演节点。
   - 场景：用户需要看最宏观的网状结构时使用。
2. **🧠 纯净推演视界 (Deep-Think Only View)**：
   - 行为：**一键隐藏**所有未参与深度思考的基础节点（如边缘人物、琐碎的闲散证据）。
   - 只保留：大模型推演出的虚拟节点（如量刑情节、要件）以及**与它们直接相连的基础节点**。
   - 场景：用户想剥离噪音，只看案件核心逻辑骨架时使用。
3. **🔍 检索链路视界 (Retrieval Chain View)**：
   - 这就是原本右侧的“子图 Tab”。将其降级为一种视图模式，专门用于展示最左侧列表点击的一条独立线索。

**交互收益**：画布还是那个大画布（支持平移缩放），但你可以像用 Photoshop 的图层一样，随时切掉无关事实的图层，只看大模型的思考结晶。

### 疑问 3：中间的“知识发现”面板本来就不展示图谱，为什么说可以释放空间？

**答复与澄清**：
这是我前一份文档表述不够严谨。
目前的真实情况是：**中间面板确实已经没有图谱 Canvas 了**。在早些时候的代码重构中，我们已经把 `renderDiscoverySubGraph` 的渲染目标移动到了右侧的 `termSubGraphTabContent` 下。
因此，中间面板现在的确只剩下纯文本的“思考过程”和“JSON 树”。

**修正后的布局规划**：
中间的 `termJsonColumn` 保持现状，继续作为**文本/数据控制台**的完美角色。
- 上半部分：JSON 树状图 / 思考过程打印输出。
- 下半部分：可以作为操作区（放置那 5 个链式推演的触发按钮）。

## 终极方案蓝图 (Blueprint)

综合上述思考，我们未来的页面功能拓扑将变得极为清晰：

| 区域 | 功能定位 | 核心交互 |
| :--- | :--- | :--- |
| **最左栏** | **案件资产库** | 展示原始文档、切片片段、检索资产列表。是案件材料的入口。 |
| **中间栏** | **AI 脑力控制台** | 容纳链式思考按钮、流式打印推演过程、展示结构化 JSON。是**逻辑引擎的监视器**。 |
| **最右栏** | **动态图谱工作台** | 唯一的、巨大的核心交互画布。 |
| *(右侧附加)*| **视界控制器** | 控制右栏显示什么。提供“全貌图”、“纯净推演图”、“特定检索链路图”的三档无缝切换。 |

在这个架构下，大模型每推演完一步，中间栏会打印出 JSON；同时右侧的主画布如果在“纯净推演视界”下，就会像动画一样凭空长出几个新节点（如“从轻处罚”），并且随着你点击中间的历史 Tab，画布上的不同节点会智能地亮起或暗去。

这个设计方案从根本上解决了大图谱的“噪音干扰”问题，并且让链式思考的过程可视化变得非常性感。如果这个逻辑推演复合你的期望，我们后续的开发就将朝着“图层过滤引擎”的方向发力。
