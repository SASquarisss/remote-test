# 法条正则提取 10 条验证报告 v2.2

## 测试范围
数据源：`data/raw/test_10_subset.csv` 的 10 条指导性案例。
提取字段：`basic_facts` + `judgment_reason` + `judgment_essence` + `related_law`。

## 核心修复与优化

| 优化项 | 说明 |
|---------|------|
| **修复 typo** | `笭` → `第` （原正则完全失效的根因） |
| **支持同法多条** | `《XX法》第A条、第B条` 可拆分为多条 |
| **扩展后缀** | 新增 `法典` / `条例` / `规定` / `公约` / `办法` |
| **非贪嚥量词** | 修复模式 B 的贪嚥匹配导致误拿后缀作为 statute 的 bug |
| **排除代词** | `本法` / `该法` / `此法` 等（支持前缀如"有本法"） |
| **排除法院误匹** | 模式 B 增加 `(?!院)` 负向前瞻，避免匹配到"最高人民法" |
| **后处理去重** | 对于带《》与不带《》的重叠版本，优先保留带条号+带书名号的 |
| **全面清理 HTML** | `使用 re.sub(r'<[^>]+>', '', text)` 替代手动替换 |

## 尚未解决的问题
1. **隐式引用捕获**：4 条案例没有显式法条，需要依赖 LLM 或案件类型映射补充。
2. **模式 C 同法多条**：司法解释类目前只支持单条提取（如"第五条、第六条"只能提取第一条）。
3. **无书名号简写**：模式 B 最多匹配 10 个字符，对于超长简写名如"涉外民事关系法律适用法"可能截断。

2. 尝试用 LLM 补充隐式引用的法条推断。
