### 3. daily_review.py 新增重试机制但缺少日志记录
- **位置**：`scripts/daily_review.py:310-327`
- **严重程度**：🟡 警告
- **描述**：新增的 `retry_on_error` 装饰器实现了指数退避重试（2s, 4s, 8s），但重试过程中没有任何日志输出。当API调用失败时，运维人员无法从日志中判断是单次失败还是多次重试后仍失败。
- **建议修复**：
```python
import logging
logger = logging.getLogger(__name__)

def retry_on_error(max_retries=3, delay=2):
    def decorator(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return fn(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        logger.error(f"{fn.__name__} failed after {max_retries} attempts: {e}")
                        raise
                    wait = delay * (2 ** attempt)
                    logger.warning(f"{fn.__name__} attempt {attempt+1} failed: {e}, retrying in {wait}s")
                    time.sleep(wait)
            return None
        return wrapper
    return decorator
```
