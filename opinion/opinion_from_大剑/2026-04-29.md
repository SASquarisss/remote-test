## 三、问题列表

### 🔴 高优先级（立即修复）

#### 1. legal_provision_extractor.py pattern3 正则存在严重缺陷
- **位置**：`scripts/legal_provision_extractor.py:93`
- **问题**：pattern3 使用 `二?百?三?十?八?九?七?六?五?四?一?十?零?百?千?` 这种逐个字符可选的正则，匹配逻辑混乱，会匹配大量无意义字符串（如"第条条"）。虽然代码中通过 `continue` 跳过了 pattern3，但遗留的死代码会造成维护困扰。
- **修复方案**：删除 pattern3，或彻底重写为基于中文数字字符集 `[一二三四五六七八九十百千万零]` 的合理正则。

```python
def chinese_to_arabic(s: str) -> str:
    if s.isdigit():
        return s
    units = {'十': 10, '百': 100, '千': 1000}
    nums = {'零': 0, '一': 1, '二': 2, '三': 3, '四': 4, '五': 5,
            '六': 6, '七': 7, '八': 8, '九': 9}
    result = 0
    current = 0
    for char in s:
        if char in nums:
            current = nums[char]
        elif char in units:
            if current == 0:
                current = 1
            result += current * units[char]
            current = 0
    result += current
    return str(result) if result > 0 else ""
```
