### 3. `daily_review.py` 中 `parse_classified_items` 正则存在潜在误匹配风险
- **位置**：`scripts/daily_review.py:136-180`
- **严重程度**：🟡 警告
- **描述**：`parse_classified_items` 使用正则 `r'\n### (\d+)\.\s*'` 分割LLM输出，但LLM可能生成 `### 1. **标题**` 或 `### 1. 标题` 等不同格式。当前 `title = body.strip().split('\n')[0].strip()` 会捕获到 markdown 标记（如 `**标题**`），虽然后续有 `re.sub(r'\*+', '', title)` 清洗，但如果标题跨行或包含其他 markdown 语法（如 `[链接](url)`），提取会不准确。
- **建议修复**：
```patch
SEARCH:
        title = body.strip().split('\n')[0].strip()
        title = re.sub(r'\*+', '', title).strip()
REPLACE:
        first_line = body.strip().split('\n')[0].strip()
        # 移除markdown标记：粗体、斜体、行内代码
        title = re.sub(r'([*_`\[\]]+)', '', first_line).strip()
        # 移除链接语法保留文本
        title = re.sub(r'\[(.*?)\]\(.*?\)', r'\1', title).strip()
```

### 4. `apply_user_confirmation.py` 的 `parse_user_confirmation` 对中文语义理解不够鲁棒
- **位置**：`scripts/apply_user_confirmation.py:72-80`
- **严重程度**：🟡 警告
- **描述**：当前使用正则 `(?<!不)同意\s*(\d+)` 来匹配"同意X"，但用户可能输入"同意 1号和3号"、"同意第1条"、"确认1"等变体。负向回顾后发 `(?<!不)` 在中文语境下对"不同意"的识别基本正确，但无法处理"不完全同意"、"同意但不接受"等复杂表达。
- **建议修复**：
  1. 扩展匹配模式，支持"确认"、"接受"、"批准"等同义词
  2. 支持范围表达（如"同意1-3"、"同意1,2,3"）
  3. 添加模糊匹配兜底：当无法解析时，将整个回复记录到日志并标记为"需人工确认"

### 5. `extract_legal_provisions_regex.py` 模式B的 statute 截断问题
- **位置**：`scripts/extract_legal_provisions_regex.py:45`
- **严重程度**：🟡 警告
- **描述**：模式B简写格式使用 `[^条款项...]{1,10}?` 限制 statute 名称最多10个字符，对于超长简写法名（如"涉外民事关系法律适用法"11字）会截断。验证报告中也明确记录了此问题（"模式 B 最多匹配 10 个字符，对于超长简写名...可能截断"）。
- **建议修复**：
```patch
SEARCH:
            r'(?:^|[^\u4e00-\u9fa5])(?<!中华人民共和国)([^条款项' + _CN_NUMS + r'\d照参根依按]{1,10}?(?:法典|条例|规定|公约|办法|法))(?!院)'
REPLACE:
            r'(?:^|[^\u4e00-\u9fa5])(?<!中华人民共和国)([^条款项' + _CN_NUMS + r'\d照参根依按]{1,20}?(?:法典|条例|规定|公约|办法|法))(?!院)'
```
同时，在 `_parse_multi_articles` 中添加对截断名称的后处理补全逻辑。

- **建议修复**：
```python
from functools import wraps
import time

def retry_on_error(max_retries=3, delay=2):
    def decorator(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return fn(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise
                    time.sleep(delay * (2 ** attempt))
            return None
        return wrapper
    return decorator

@retry_on_error(max_retries=3)
def analyze_with_llm(blocks) -> str:
    ...
```
