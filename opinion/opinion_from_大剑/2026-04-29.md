### 5.2 改进建议

1. **增加 Few-shot 示例**：在提示词末尾增加 2-3 个完整 JSON 示例（覆盖刑事、民事、调解三种类型）
2. **增加输出校验指令**：明确要求 LLM 在输出前自查 "article 是否为空"、"result_type 是否符合案件类型"
3. **增加长度控制**：对 `guiding_points` 和 `key_facts` 增加 "不得超过 X 字" 的硬性约束
4. **分离系统提示与用户提示**：当前所有内容都在 user prompt 中，建议将提取规则放入 system prompt，仅案件文本放入 user prompt
